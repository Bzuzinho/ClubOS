## Regra de mudança após go-live

A partir deste fecho:
1. bugs de produção entram como bugfixes isolados;
2. novas funcionalidades entram como evolução planeada;
3. dívida não bloqueante não deve impedir a operação corrente;
4. alterações em fontes de verdade, permissões, financeiro/fiscal ou lifecycle crítico mantêm CI completa e deploy atómico obrigatório;
5. P2 permanece fechado salvo nova evidência concreta de ownership concorrente.
